# NekoAR

スマホのカメラ越しの部屋に猫を出現させる WebAR アプリです。猫は床や机などの面を認識して、歩いたり、座ったり、机に飛び乗ったりします。
猫の見た目は写真や動画から、鳴き声は動画・音声から学習して、あなたの猫に近づけます。

- ビルド不要の静的サイトです（HTML + ES Modules。Three.js と MediaPipe は CDN から読み込みます）
- 写真・動画・音声の解析はすべて端末内で行います（任意の「Claudeで高精度解析」を使った時だけ、写真が Anthropic API に送信されます）

## できること

| 機能 | 内容 |
| --- | --- |
| AR表示 | WebXR `immersive-ar`。ヒットテストで水平面を集め、高さごとに「床」「机」「椅子」などのレベルに分けた地図を作る |
| 実空間に合わせた行動 | 地図の上だけを経路探索して歩く。高い面（机・椅子・箱など）を見つけると、手前まで歩いてお尻を振ってから飛び乗る。飛び降りる、ユーザーに寄ってくる、座る、香箱座り、毛づくろい、伸び |
| 操作 | 面をタップ → そこへ来る（別の高さならジャンプして移動）／猫をタップ → なでる（ゴロゴロ）／「呼ぶ」→ 足元に来る |
| 見た目の学習 | 写真（複数枚可）または動画のフレームから、猫の領域を切り出して毛色・柄（トラ・三毛・サビ・ポインテッド・白ぶちの量など）を推定 |
| 鳴き声の学習 | 動画・音声から猫の鳴き声の区間だけを自動で切り出し（人の声や物音は除外）、その子の声として再生。足りない種類は学習した声の高さで合成 |
| デモルーム | AR非対応の端末（PC・iPhone）でも、仮想の部屋で同じ行動ロジックを試せる |

## 対応端末

| 端末 | AR | デモルーム・学習 |
| --- | --- | --- |
| Android（ARCore対応）+ Chrome | ○ | ○ |
| Meta Quest ブラウザ | ○（平面検出で机などのラベルも利用） | ○ |
| iPhone / iPad（Safari） | ×（Safari が WebXR の AR に未対応） | ○ |
| PC ブラウザ | × | ○ |

## 動かし方

### PC で試す（デモルーム・学習）

```bash
python serve.py
```

http://localhost:8080 を開きます。「デモルームで試す」で、机・椅子・箱・棚のある部屋で猫の行動を確認できます（ドラッグで視点移動、見回した場所の面が見つかっていきます）。

### スマホで AR を試す

WebXR の AR は **HTTPS**（または localhost）でしか動きません。次のどれかで公開してください。

1. **静的ホスティングに置く（おすすめ）**: このフォルダをそのまま GitHub Pages / Netlify / Cloudflare Pages / Vercel などに置くだけで動きます。
2. **Android を USB でつなぐ**: PC で `python serve.py` → Android の USB デバッグを有効にして PC の Chrome で `chrome://inspect` → 「Port forwarding」で `8080 → localhost:8080` を設定 → スマホの Chrome で `http://localhost:8080` を開く。
3. **トンネル**: `cloudflared tunnel --url http://localhost:8080` などで一時的な HTTPS URL を発行。

AR での流れ:
1. 「ARで猫を出す」→ カメラを許可
2. 床や机を映しながらスマホをゆっくり左右に動かす（見つかった面が点で表示されます）
3. 猫を出したい場所をタップ
4. 机などを映すと「机（高さ 72cm）を見つけました」と表示され、猫が飛び乗りに行きます

## 「学習」の仕組み（いまの実装）

### 見た目（写真・動画）
1. **DeepLab v3**（MediaPipe Image Segmenter）で画像から猫の領域を切り出す
2. 領域内の画素を CIELAB 色空間で **k-means** → 毛色パレット。白い毛を基準にホワイトバランスと露出を補正
3. 柄の判定:
   - **ImageNet 画像分類**（EfficientNet-Lite0: "tabby", "Siamese cat", "Persian cat" など）のスコア
   - **縞の強さ**（局所平均との明度差）と**塊の太さ**（黒・茶の領域が細い縞か太いパッチか）
   - これらから トラ（茶トラ／キジトラ／サバトラ）・三毛・サビ・ポインテッド・単色 を判定
4. 白の割合と位置（顔の上部か）から「白ぶちの量」「顔の白」を推定
5. 結果は手続き的な 3D 猫モデルのパラメータになり、GPU シェーダーで部位ごとに毛柄を塗り分けます（足先→胸→お腹→顔→背中の順に白くなる、など実際の猫の白ぶちの出方に合わせています）

写真が多いほど（角度違いが多いほど）安定します。目の色は写真から直接は測っていないため、毛色から推定しています。

**Claudeで高精度解析（任意）**: 設定タブで Anthropic の API キーを入れると、Claude（`claude-opus-5-5`）が写真を見て、毛柄・部位ごとの白・目の色・体型などを構造化 JSON で返し、それを反映します。キーはブラウザ内にのみ保存されます。公開サイトで使う場合は、キーをブラウザに置かずに済むよう、小さなサーバー経由にすることを検討してください。

### 鳴き声（動画・音声）
1. 音声トラックをデコード → 短時間エネルギーで「音が鳴っている区間」を検出
2. **YAMNet**（AudioSet 521クラス）で各区間が Meow / Purr / Hiss / Cat かを判定し、人の声・物音を除外
3. 自己相関でピッチ（f0）を推定。短く上がる声は「くるる」に分類
4. 切り出した声を端末内（IndexedDB）に保存。鳴く時は毎回少し高さを変えて再生し、AR では猫の頭の位置から聞こえるよう立体定位
5. クリップのない種類（ゴロゴロ等）は、学習した声の高さに合わせたフォルマント合成で鳴きます

js/cat/CatModel.js        手続き的な猫モデル（関節付き）

js/world/DemoMode.js      仮想の部屋（ARと同じ情報の流れで面を発見）

js/learn/video.js         動画→フレーム

## 既知の制限

- **遮蔽なし**: 猫が机の向こう側に回っても、机で隠れずに手前に描画されます
- **見た目は「パラメータ推定」**: 写真から毛柄・色・体型を推定して共通の猫モデルに反映する方式で、その子の顔立ちや模様の位置までは再現しません
- **声は「実録音の再利用＋合成」**: 新しい鳴き方を生成するモデルではありません
- iPhone では AR が使えません（デモルームは使えます）

## 今後の拡張案

1. **遮蔽**: WebXR Depth Sensing で実物の奥に猫が隠れるように
2. **見た目の本格的な再現**: 動画から画像→3D生成（3D Gaussian Splatting や image-to-3D モデル）＋自動リギングを GPU サーバーで行い、glTF として読み込む
3. **声の生成**: 切り出したクリップで小さな音声生成モデルを学習し、新しい鳴き方を合成
4. **iPhone 対応**: ネイティブ版（Unity AR Foundation など）なら ARKit の平面分類（table / seat / floor）で「机」を直接認識できる
5. **空間の記憶**: アンカーで部屋を覚え、次回も同じ場所に猫がいるように
